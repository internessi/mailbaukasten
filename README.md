# Internessi Mailing-Generator

Öffentlicher Mailing-Generator für `https://www.internessi.de/mailing/`.

## Aktueller Stand

Planung und zwei HTML-Designvorlagen sind vorhanden. Der Generator ist noch
nicht implementiert. Entwicklung und Erprobung erfolgen zunächst lokal im
Projektordner; eine Veröffentlichung ist ein späterer Schritt.

- [Projektbeschreibung](PROJEKT.md): Anforderungen, Bedienung und Umsetzungshinweise.
- [Design 1](Internessi-Mailvorlage.html): markanter Kopf und strukturierte Bereiche.
- [Design 2](Internessi-Mailvorlage-Design-2.html): heller Briefstil.

Geplant sind ein Editor links, eine Live-Vorschau rechts, zwei Designs,
fünf Farbpaletten und eine abschließende Vorschau mit HTML-Download.
Teilbare öffentliche Adressen für erzeugte Mailings sind vorerst ausgeschlossen.

## Arbeiten am Projekt

`AGENTS.md` beachten. Der Ordner `sources/` enthält synchronisierte, unveränderliche
Referenzen und ist von der Git-Versionierung ausgeschlossen.

Das Repository kann sowohl hier als auch später in VS Code weiterbearbeitet werden.
Ein Build- oder Startbefehl wird ergänzt, sobald die Anwendung implementiert ist.
